**Açıklama / Description (4000)**
```
Çoğu Markdown editörü senin metnini kendi biçimine çevirir, sonra geri
verirken bir şeyler kaybolur. ProMDEditor çevirmez. Yazdığın karakter diskte
duran karakterdir — git diff'in temiz kalır, dosyanı hangi araçla açarsan aç
aynı görünür.

Karşılığında biçimi görmekten vazgeçmezsin: başlıklar gerçek boyutunda,
kalın gerçekten kalın, kod tek aralıklı. Markdown işaretleri soluk gri durur,
yani hem biçimi görürsün hem kaynağı.

CANLI BİÇİMLENDİRME
Başlıklar gerçek boyutunda görünür, **kalın** kalın, *italik* italik, kod tek
aralıklı ve arka planlı, bağlantılar renkli görünür. Markdown işaretleri soluk
gri kalır, yani biçimi görürsün ama kaynağı kaybetmezsin.

⌘B, ⌘I, ⌘K, ⌘E ve tüm biçim menüsü seçime uygulanır; ikinci basışta kaldırır.
Return tuşu liste ve görev listelerini otomatik devam ettirir, boş maddede
listeyi bitirir.

DOSYA KARŞILAŞTIRMA
⌘4 ile açık belgeyi başka bir .md veya .txt dosyasıyla yan yana karşılaştır.
Satır satır hizalanmış görünüm, kelime bazlı vurgulanmış farklar, değişmeyen
uzun bölümler katlanır. Her fark bloğu çift yönlü aktarılabilir: ← karşı
dosyadaki bölümü açık belgeye alır, → bölümü karşı dosyaya yazar. Karşı dosya
açık belgeden bağımsız kaydedilir ve ProMDEditor dışında değiştiyse üzerine
yazmadan önce onay ister.

QUICK LOOK
Finder'da bir .md dosyası seçip boşluk tuşuna bas — render edilmiş halini
görürsün. Önizleme uygulamayla aynı temayı ve fontları kullanır.

IPHONE VE IPAD
Aynı .md dosyasını iPhone ve iPad’de biçimli oku. Dosyalar’dan, Mattermost
paylaşım sayfasından veya Quick Look ile açılır. Tema, Mac’teki katalogla
aynıdır.

38 TEMA

Kanagawa, Vitesse, Catppuccin, Gruvbox, Rosé Pine, Tokyo Night, Dracula,
Monokai, Nord, Cobalt2, Panda, Material Ocean ve yüksek kontrast seçenekleri.
Hepsi WCAG AAA hedefine göre ayarlandı: gövde metni en az 8:1, bağlantı ve
soluk metin en az 4.6:1, kod bloğu en az 7:1 kontrast oranında. Tema tek adla
seçilir; editör ve önizleme aynı temaya geçer.

TİPOGRAFİ
Sistemdeki tüm yazı tipleri arasından gövde, başlık, tek aralıklı ve editör
fontunu ayrı ayrı seç. Punto, satır yüksekliği, içerik genişliği, iki yana
yaslama ve daktilo modu ayarlanabilir.

DAHASI

- Bölünmüş görünüm ve kaydırma senkronizasyonu (⌘1 / ⌘2 / ⌘3)

- Zengin metin ve HTML olarak kopyalama

ProMDEditor açık kaynaktır (MIT). Markdown ayrıştırma için Apple'ın
```

**Description (4000)**
```
Most Markdown editors translate your text into their own format, and something
goes missing on the way back. ProMDEditor never translates. The character you
type is the character on disk — your git diffs stay clean, and the file looks
the same in whatever tool opens it next.

You give up nothing in return: headings render at their real size, bold is
genuinely bold, code is monospaced. The Markdown markers stay visible in muted
grey, so you see the formatting and the source at once.

LIVE FORMATTING
Headings render at their real size, **bold** is bold, *italic* is italic, code
is monospaced on a tinted background, links are coloured. Markdown markers stay
visible in muted grey, so you see the formatting without losing the source.

⌘B, ⌘I, ⌘K, ⌘E and the full format menu apply to the selection and toggle off
on a second press. Return continues lists and task lists automatically, and
ends the list on an empty item.

FILE COMPARISON
Press ⌘4 to compare the open document with another .md or .txt file side by
side. Lines are aligned, differences highlighted word by word, and long
unchanged stretches fold away. Every diff block moves in either direction:
← pulls the other file's block into the open document, → writes your block out
to the other file. The other file is saved independently, and if it changed
outside ProMDEditor you are asked before anything is overwritten.

QUICK LOOK
Select a .md file in Finder and press space to see it rendered. The preview
uses the same theme and fonts as the app.

IPHONE AND IPAD
Read the same .md file, formatted, on iPhone and iPad. Open it from Files,
the Mattermost share sheet, or Quick Look. Themes come from the same catalog
as the Mac app.

38 THEMES
Istanbul Day/Night (default), Çağla Day/Night, GitHub, Ayu, Night Owl,
Kanagawa, Vitesse, Catppuccin, Gruvbox, Rosé Pine, Tokyo Night, Dracula,
Monokai, Nord, Cobalt2, Panda, Material Ocean and high-contrast variants. All
are tuned to WCAG AAA targets: body text at least 8:1, links and muted text at
least 4.6:1, code blocks at least 7:1. You pick one theme name, and both the
editor and the preview switch to it.

TYPOGRAPHY
Pick body, heading, monospace and editor fonts independently from every font
installed on your Mac. Size, line height, content width, justification and a
typewriter mode are all adjustable.

ALSO
- GFM support: tables, task lists, strikethrough, fenced code
- Split view with scroll sync (⌘1 / ⌘2 / ⌘3)
- Export as HTML, PDF, Word, and rich text
- Copy as rich text or HTML

ProMDEditor is open source (MIT) and uses Apple's swift-markdown library for
parsing.
```
